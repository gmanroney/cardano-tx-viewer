# Push to GitHub

Your code is ready to push! Run these commands:

```bash
cd /home/gerard/claude/cardano-tx-viewer

# Add the remote
git remote add origin https://github.com/gmanroney/cardano-tx-viewer.git

# Push to GitHub
git push -u origin main
```

When prompted for credentials:
- Username: gmanroney
- Password: Use your Personal Access Token (PAT)

Or use this single command with your token embedded:
```bash
git push https://YOUR_TOKEN@github.com/gmanroney/cardano-tx-viewer.git main
```

Replace YOUR_TOKEN with your actual token.
